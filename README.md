Этот проект был создан по большей части для нашего приватного сервера, однако было принято решение поделиться решением с публикой. Это небольшой и ни на что не претендующий мод.

Как он работает? Его необходимо добавить на клиент и сервер - и тогда игровой чат и Telegram синхронизируются, сообщения игроков на сервере будут видны в Telegram и наоборот.

Необходимо также настроить конфиг (лучше использовать отдельный чат для этого, потребуется telegram бот, необходимо указать id беседы и бота в конфиге)

Что ещё было добавлено:
- Виден текст описания к картинке
- Мод на клиенте стал опционален (однако без него просмотреть картинку из чата будет невозможно)
- Оформление цветом
- Картинки в виде кэша (хранятся в оперативной памяти и подчищаются)
- Вызов команд прямо из чата telegram (и обозначение админов, настраивается в конфиге)
